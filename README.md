# Rastgele Kahve Falı Üreteci

## Bu Nedir?

Bu, insanlık tarihinin en önemli projelerinden biridir. Türk kahvesi falını dijital çağa taşıyan, geleceği şekillendiren, ruhunuzu okuyan bir yazılım.

Aslında hiçbiri değil. Sadece rastgele cümleler üretiyor. Ama abartmak serbest.

## Nasıl Çalıştırılır?

```bash
python kahve_fali.py
```

Veya isim vererek:
```bash
python kahve_fali.py Ahmet
```

Çıktı: 3 tane saçma sapan fal. Garanti eğlence.

## Özellikler

- %0 doğruluk oranı
- %100 güldürme garantisi
- Kahve içmenizi gerektirmez (ama içerseniz daha iyi)
- Geleceği değiştirmez ama gülümsetir

## Uyarı

Bu yazılım hiçbir şekilde gerçek falcıların yerini tutmaz. Gerçek falcılar daha pahalıdır.
